## 🛠️ Compilation and Execution

All programs are written in standard C++ (C++11 standard). Each program is standalone and includes its own `main()` function.

### Prerequisites
- GCC / MinGW (`g++` compiler) or Clang

### How to Compile & Run

#### On Windows (PowerShell / Command Prompt):
```powershell
# Example: Compiling Practical 1
g++ -std=c++11 practical_01_arrays.cpp -o practical_01_arrays.exe

# Running the executable
.\practical_01_arrays.exe
```

#### On Linux / macOS:
```bash
# Example: Compiling Practical 1
g++ -std=c++11 practical_01_arrays.cpp -o practical_01_arrays

# Running the executable
./practical_01_arrays
```
